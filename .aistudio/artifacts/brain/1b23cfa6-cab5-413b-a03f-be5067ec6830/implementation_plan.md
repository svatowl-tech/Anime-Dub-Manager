# План доведения функционала тайминга до продакшен-уровня и модульный рефакторинг

> **Примечание**: По запросу пользователя блок сведения (Mixing) полностью исключен из плана. Работа сосредоточена исключительно на доведении модуля **«Тайминг»** до эталонного production-качества, исправлении всех скрытых дефектов и глубоком архитектурном рефакторинге.

---

## 1. Аудит текущего состояния и проверка работоспособности функций тайминга

Файл `TimingPanel.tsx` в текущем виде представляет собой монолит объемом более **4700 строк**. Внутри перемешаны декодирование аудио, математика VAD, рендеринг Canvas, клавиатурные обработчики, управление состоянием клипов и модальные окна.

### Анализ работоспособности существующих функций:
1. **Воспроизведение и Web Audio Engine**:
   * *Проблема*: При частом скролле, масштабировании (зуме) или смене позиции курсора периодически происходит рассинхронизация плейхеда Canvas с аудио-контекстом, а также накапливаются не остановленные `AudioBufferSourceNode`, что вызывает заикания и утечки памяти.
   * *Задача*: Внедрить централизованный аудио-движок на базе `requestAnimationFrame` с аппаратной привязкой ко времени `AudioContext.currentTime` и корректным lifecycle источников звука.
2. **Инструменты редактирования клипов (Split, Trim, Nudge, Snap)**:
   * *Проблема*: Разрезание клипа (`S`), подрезка границ и сдвиг стрелками реализованы через прямые мутации в гигантском стейте, что приводит к потере привязки к репликам субтитров и сбоям истории отмены (Undo/Redo).
   * *Задача*: Вынести операции с клипами в детерминированный сервис с поддержкой глубокого Undo/Redo и защитой от пересечений с нулевой длительностью.
3. **Снеппинг (Привязка)**:
   * *Проблема*: Привязка к границам субтитров работает нестабильно из-за неточного сопоставления стилей/имен в ASS и отсутствия привязки к нулевым фазовым переходам (zero-crossing), из-за чего на стыках возникают щелчки (clicks/pops).
   * *Задача*: Внедрить микрофейды (5–10 мс) на краях срезов и прецизионный снеппинг.
4. **Паспорт тайминга (Экспорт и синхронизация)**:
   * *Проблема*: При сохранении паспорта серии не всегда сохраняются локальные смещения отдельных дублей, если дорожка была переименована или заменена фиксом.
   * *Задача*: Обеспечить персистентность по уникальным `clipId` и хэшам исходных файлов.

## 2. Архитектурный рефакторинг (Модульная декомпозиция монолита)

Вместо одного 4700-строчного файла создается чистая, расширяемая архитектура с разделением ответственности:

```
src/
├── services/timing/
│   ├── AudioVADEngine.ts            // Адаптивная калибровка шума, энергетический VAD, детекция речи
│   ├── SubtitleAlignmentService.ts   // Сопоставление дорожек и реплик с субтитрами ASS (Dice/морфология)
│   ├── SmartPauseBreathingEngine.ts  // Алгоритм сжатия/расширения пауз между словами без искажения голоса
│   ├── TimingCollisionResolver.ts    // Предотвращение наездов реплик разных персонажей
│   └── TimingPassportSerializer.ts   // Надежная сериализация, валидация и экспорт тайминг-паспорта
├── hooks/timing/
│   ├── useTimingAudioEngine.ts       // Управление AudioContext, буферами дорожек, воспроизведением, лупом
│   ├── useTimingClips.ts             // Стейт клипов, разрезание, тримминг, сдвиг, стек Undo/Redo
│   ├── useTimingCanvasRender.ts      // Высокопроизводительный рендеринг формы волны (DPI compensation, culling)
│   └── useTimingShortcuts.ts         // DAW-хоткеи (Space, S, Del, Z, стрелки, модификаторы Shift/Alt)
└── components/timing/
    ├── TimingToolbar.tsx             // Верхняя панель: транспорт, масштаб, авто-тайминг, экспорт
    ├── TimingTrackHeaderList.tsx     // Левая колонка: дорожки дабберов, Mute/Solo, громкость
    ├── TimingWaveformCanvas.tsx      // Центральный таймлайн с формой волны, маркерами и плейхедом
    ├── TimingSubtitleDrawer.tsx      // Нижняя/боковая панель реплик с индикацией расхождения
    ├── SmartPauseModal.tsx           // Интерактивное модальное окно авто-подгонки с визуальным Diff
    └── TimingPanel.tsx               // Компактный оркестратор (~250-300 строк)
```

## 3. Алгоритм интеллектуальной авто-подгонки дорожек под субтитры (Smart Pause Breathing)

Главная функциональная инновация для ускорения работы таймера:

1. **Двухуровневая детекция пауз**:
   * Внешние паузы (до и после фразы): свободное смещение под границы субтитра ASS.
   * Внутренние межсловные паузы: выявление пауз длительностью $\ge 120\text{ мс}$ внутри реплики.
2. **Адаптивное масштабирование пауз (Smart Pause Breathing)**:
   * **Когда реплика длиннее субтитра**:
     - Звучащие слова остаются со 100% исходной скоростью и естественным тембром.
     - Сокращаются исключительно внутренние паузы и вдохи (до безопасного предела 80–100 мс).
     - Если лимит пауз исчерпан, предлагается аккуратный WSOLA-стретч ($\le 8\%$) только в крайнем случае.
   * **Когда реплика короче субтитра**:
     - Внутренние паузы пропорционально расширяются для синхронного попадания ключевых акцентов в артикуляцию оригинала.
3. **Разрешение коллизий и нахлестов**:
   * Анализ реплик соседних персонажей: если реплика персонажа А налезает на реплику персонажа Б, алгоритм автоматически поджимает хвостовую паузу реплики А и задает микросдвиг входа реплики Б, сохраняя естественную дистанцию диалога (не менее 60–100 мс).
4. **Интерактивный предпросмотр изменений (Visual Diff)**:
   * До применения изменений пользователь видит таблицу со всеми сдвигами: оригинальная длительность $\rightarrow$ новая длительность, дельта пауз, статус совпадения (зеленый/желтый/красный) с возможностью исключить отдельные реплики.

## 4. Гарантия работоспособности всех интерактивных элементов (Zero Broken Clicks)

Каждая функция обязана иметь законченный рабочий обработчик:
* **Кнопки транспорта**: Play/Pause, перемотка в начало, перемотка к началу выбранной реплики субтитра.
* **Масштабирование (Zoom)**: Колесико мыши с зажатым `Ctrl/Cmd` центрируется строго на позиции курсора; кнопки `+` и `-` масштабируют с шагом 1.25x без сброса позиции скролла.
* **Выделение и разрезание**:
   * Клик по таймлайну ставит курсор.
   * Нажатие клавиши `S` или кнопки «Разрезать» делит активный клип ровно по позиции курсора с созданием двух независимых сегментов и добавлением микрофейда.
   * Подрезка левого/правого края клипа мышью с визуальной подсветкой границы и привязкой к сетке.
* **Сдвиг фраз (Nudge)**:
   * Стрелки влево/вправо сдвигают выбранный клип на 10 мс (с Shift — на 100 мс).
* **Сброс и восстановление**:
   * Возможность вернуть любой клип или дорожку в исходное состояние (Reset to Raw Take).
* **Экспорт**:
   * Экспорт финального сведенного тайминг-паспорта для звукорежиссера и экспорт готовых синхронизированных WAV дорожек.

## 5. Этапы реализации

1. **Этап 1: Выделение базовых сервисов**:
   * Создание `AudioVADEngine.ts` и `SubtitleAlignmentService.ts`.
   * Создание `SmartPauseBreathingEngine.ts` с математикой распределения пауз.
2. **Этап 2: Выделение аудио-движка и хуков**:
   * Создание `useTimingAudioEngine.ts` (надежное воспроизведение, синхронизация плейхеда).
   * Создание `useTimingClips.ts` (операции редактирования, история Undo/Redo).
   * Создание `useTimingShortcuts.ts` (клавиатурные комбинации).
3. **Этап 3: Декомпозиция компонентов интерфейса**:
   * Создание `TimingWaveformCanvas.tsx` с оптимизированным Canvas-рендерингом.
   * Создание `TimingToolbar.tsx` и `TimingTrackHeaderList.tsx`.
   * Создание `SmartPauseModal.tsx` с предпросмотром авто-подгонки.
   * Сборка обновленного `TimingPanel.tsx` в качестве компактного оркестратора.
4. **Этап 4: Верификация и стресс-тестирование**:
   * Проверка воспроизведения на длинных эпизодах (20+ минут).
   * Тестирование нарезки, тримминга, Undo/Redo и снеппинга.
   * Проверка алгоритма компенсации пауз на несовпадающих по темпу репликах.
   * Проверка компиляции `compile_applet` и линтинга.
