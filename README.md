## 💡 Для чего создано приложение?

Создание качественного дубляжа и закадровой озвучки аниме или сериалов — это сложный конвейер:
1. **Переводчикам** нужно вовремя подготовить и вычитать субтитры.
2. **Кураторам** приходится вручную нарезать скрипты по персонажам и рассылать десяткам даберов в Telegram.
3. **Даберам** требуется видеть контекст сцены, слышать оригинальные интонации и следить за липсинком.
4. **Звукорежиссеру** необходимо собирать сотни разрозненных аудиофайлов, сверять тайминги и устранять ошибки.

**Anime Dub Manager полностью автоматизирует этот процесс**, превращая хаос в чатах в упорядоченный, прозрачный и ускоренный в 3–5 раз рабочий процесс.

## ✨ Ключевые возможности

### 🤖 1. Интеллектуальная Диаризация и Распознавание Речи
- **Распознавание речи с Whisper / WhisperLiveKit**: Локальная транскрипция аудиодорожек без необходимости отправлять приватные файлы на внешние серверы.
- **Диаризация спикеров с PyAnnote**: Автоматическое разделение реплик по разным голосам с высокой точностью.
- **Детекция лиц и говорящих в кадре (Active Speaker)**: Визуальный анализ лиц на видео для автоматического сопоставления реплики с персонажем на экране.
- **Инспектор голосов и кадров (Character Voice & Frame Inspector)**:
  - Просмотр точного стоп-кадра и прослушивание аудиофрагмента для каждой реплики.
  - Быстрое переназначение реплики другому персонажу через контекстное меню в один клик.
  - Спектрограмма и таймлайн для точной подгонки начала и конца реплики.

### 📝 2. Управление субтитрами (ASS / SRT) и OCR Hardsub
- **Визуальный OCR-риппер хардсаба**: Извлечение вшитых в видео субтитров с помощью Tesseract.js с возможностью точечного выделения области кадра (Crop Zone).
- **Индивидуальная нарезка скриптов**: Мгновенное разделение общего ASS-файла на персональные тексты для каждого актера озвучки с подсчетом количества реплик.
- **Контроль качества субтитров (QA)**: Проверка скорости чтения (CPS — Characters Per Second), слишком длинных строк, пересечений по времени и коллизий стилей.
- **Интегрированный переводчик**: Перевод субтитров через локальные нейросети (M2M100 / NLLB) или LLM API (OpenRouter).

### 🎧 3. Интерактивная Панель Контроля Качества (QA Player & Fixes)
- **Мультитрековый плеер в реальном времени**: Прослушивание присланных аудиодорожек даберов поверх оригинального видеоряда без предварительного перекодирования.
- **Осциллограмма Wavesurfer.js**: Наглядное отображение звуковой волны для проверки попадания в тайминг и губы персонажей (липсинк).
- **Конструктор правок (Фиксов)**: Маркировка тайм-кодов с дефектами и генерация структурированных отчетов для дабера в один клик.

### 🎛️ 4. Инструменты для Звукорежиссера
- **Экспорт для DAW**: Автоматическое структурирование и пакетный экспорт аудиофайлов для Reaper, Adobe Audition, FL Studio, Cubase.
- **Нормализация и конвертация**: Быстрая пакетная обработка аудио через встроенный FFmpeg.

### 🌐 5. Интеграции и Сетевые Возможности
- **Синхронизация с Shikimori и MyAnimeList (MAL)**: Автозаполнение карточки тайтла (синопсис, количество серий, постеры, список персонажей, сейю).
- **Облачный бэкап Яндекс.Диск**: Загрузка проектов и медиа в облако по протоколу OAuth.
- **Встроенный WebTorrent / Nyaa клиент**: Скачивание видео исходников по Magnet-ссылкам прямо внутри приложения.
- **YouTube / RuTube загрузчик**: Загрузка роликов и серий по прямым ссылкам через `youtube-dl-exec`.
- **Telegram Bot / Client**: Автоматическая рассылка скриптов и уведомлений команде.

### 🎨 6. Генератор Обложек (CoverGenerator)
- Создание промо-постеров и обложек для соцсетей (VK, Telegram, YouTube).
- Захват кадра из видео, наложение логотипа, разделительных узоров и типографики (Russo One, Inter, JetBrains Mono).

### 📊 7. Аналитика и Статистика Команды (StatsPanel)
- Анализ продуктивности даберов, звукорежиссеров и кураторов.
- Интерактивные графики (Recharts) сроков сдачи, процента правок и объема выполненных реплик.
- Таблица лидеров и система наград для мотивации команды.

## 🛠 Архитектура и Технологический Стек

```
├── electron/                  # Главный процесс Electron (IPC, системные вызовы, безопасность)
│   ├── main.cjs               # Точка входа Electron
│   ├── preload.cjs            # Изолированный Preload с типизированным IPC-мостом
│   └── services/              # Фоновые сервисы (FFmpeg, Telegram, Torrent, Python Sidecars)
├── src/                       # Рендерер (React 19 + TypeScript)
│   ├── components/            # UI-компоненты (Diarization, QA, OCR, Subtitles, Stats)
│   ├── lib/                   # Клиентская бизнес-логика и утилиты
│   └── types.ts               # Глобальные интерфейсы и типы данных
├── scripts/                   # Скрипты сборки, генерации иконок и загрузки зависимостей
│   ├── generate-icons.cjs     # Кроссплатформенный генератор иконок (.ico, .icns, .png)
│   ├── generate-metadata.js   # Генератор метаданных релиза и коммитов
│   ├── download-ffmpeg.js     # Автозагрузчик бинарников FFmpeg / FFprobe
│   └── prepare-sidecars.js    # Подготовка локальных ML-моделей и сайдкаров
└── assets/                    # Ресурсы приложения (иконки, бинарные утилиты, модели)
```

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Motion, Lucide Icons, Recharts, Wavesurfer.js
- **Backend / Desktop**: Electron v41, Express, Node.js v20
- **Media Engine**: FFmpeg (статические сборки под каждую ОС), Fluent-FFmpeg
- **AI / ML**: ONNX Runtime (PyAnnote Segmentation 3.0, Xenova M2M100, Whisper GGML)

## 🚀 Быстрый старт

### Требования
- **Node.js** v18 или v20 (LTS)
- **npm** v9+ или **bun**
- **Git**

### Установка и запуск в режиме разработки

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/SvatOwl/anime-dub-manager.git
cd anime-dub-manager

# 2. Установите зависимости
npm install

# 3. Сгенерируйте иконки и метаданные
npm run generate:icons

# 4. Запустите в режиме разработки (React + Electron)
npm run electron:dev
```

## 🎨 Генерация кроссплатформенных иконок

Для обеспечения идеального вида ярлыка приложения на всех операционных системах в проекте реализован скрипт `scripts/generate-icons.cjs`.

Он автоматически генерирует:
- **Windows (`assets/icon.ico`, `build/icon.ico`)**: Мульти-размерный контейнер ICO, содержащий разрешения 256x256, 128x128, 64x64, 48x48, 32x32 и 16x16.
- **macOS (`assets/icon.icns`, `build/icon.icns`)**: Контейнер Apple Icon Image с тегами Retina (512x512, 256x256, 128x128, 64x64, 32x32, 16x16).
- **Linux (`assets/icon.png`, `build/icons/*.png`)**: Набор PNG-иконок для настольного меню FreeDesktop и AppImage.

Запуск вручную:
```bash
npm run generate:icons
```
*(Скрипт автоматически вызывается перед каждой сборкой приложения)*.

## 📦 Автоматическая сборка и Релизы на GitHub (CI/CD)

В репозитории настроен автоматический рабочий процесс GitHub Actions (`.github/workflows/release.yml`).

### 🚀 Как происходит автоматический релиз:

Вам **достаточно просто закоммитить изменения и запушить их в ветку `main`** (или создать тег `v*`):

```bash
# 1. (Опционально) Обновите версию в package.json, если это мажорный/минорный апдейт
# Например: "version": "1.2.0"

# 2. Закоммитьте и отправьте изменения на GitHub
git add .
git commit -m "feat: добавлена новая панель инспектора реплик"
git push origin main
```

### ⚡ Что делает GitHub Actions автоматически:
1. **Считывает версию** из `package.json` (например, `v1.2.0`).
2. **Создает релиз на GitHub** со списком изменений и подробным описанием.
3. **Запускает параллельную сборку** на 3 независимых виртуальных машинах:
   - 🪟 **Windows (`windows-latest`)**:
     - `Anime Dub Manager Setup 1.2.0.exe` (Классический установщик NSIS)
     - `Anime Dub Manager Portable 1.2.0.exe` (Портативная версия без установки)
   - 🍏 **macOS (`macos-latest`)**:
     - `Anime Dub Manager-1.2.0.dmg` (Установщик macOS с перетаскиванием в Applications)
     - `Anime Dub Manager-1.2.0-mac.zip` (Архив для быстрого запуска)
   - 🐧 **Linux (`ubuntu-latest`)**:
     - `Anime Dub Manager-1.2.0.AppImage` (Универсальный запускной файл для любого Linux)
     - `anime-dub-manager_1.2.0_amd64.deb` (Пакет для Ubuntu / Debian / Mint)
4. **Автоматически прикрепляет собранные бинарники к Релизу** — пользователи могут сразу скачать нужную версию во вкладке **Releases**!

### ⚙️ Настройка прав репозитория (однократно):
Чтобы GitHub Actions мог публиковать бинарники в раздел Releases:
1. Откройте ваш репозиторий на GitHub.
2. Перейдите в **Settings** ➔ **Actions** ➔ **General**.
3. В секции **Workflow permissions** выберите **Read and write permissions**.
4. Нажмите **Save**.
