**Anime Dub Manager** — полноценная студия для озвучки и фандаба в одном приложении: от поиска серии и подготовки субтитров до нейросетевой очистки голоса, автотайминга, сведения и выпуска готового релиза.

Работает как **классическое приложение на ПК** (Windows / macOS / Linux) или как **автономный сервер на Umbrel OS / Docker**, которым можно управлять с компьютера, телефона и через локального AI-агента.

## 🌟 Чем круто приложение

Создание одной серии в озвучке обычно разбросано по десятку программ и чатов: торрент-клиент, Aegisub, рассылка скриптов даберам в Telegram, прослушивание десятков дорожек вручную, борьба с шумом в микрофонах, ручная подгонка таймингов, сведение и рендер.

**Anime Dub Manager объединяет весь конвейер в одной системе и убирает рутину:**

- **Вычисления живут на сервере, а вы управляете откуда угодно** — разверните ADM на домашнем сервере **Umbrel OS** (x86_64 или ARM64 / Raspberry Pi 5), и все скачивания, нейросети, автотайминг и рендер видео будут работать там 24/7. С ноутбука или телефона вы открываете лёгкий веб-интерфейс, загружаете/скачиваете файлы и принимаете работу.
- **Локальный AI-агент может заменить куратора в рутине** — в ADM встроен полноценный слой управления для локальных моделей (**MCP**, **REST API + OpenAPI 3.1** и **CLI**). Агент сам находит серию, ставит её на скачивание, чистит субтитры, распределяет роли по даберам, проверяет присланные дорожки через Whisper QA и выносит спорные решения вам на проверку.
- **Контроль человека без постоянного надзора** — когда агенту нужно ваше слово (утвердить каст, проверить бракованную реплику или разрешить сборку релиза), он присылает карточку во **Входящие куратора** в веб-интерфейсе и дублирует её в **Telegram-бота** с кнопками **«Одобрить»** / **«Отклонить»**. Вы отвечаете в один тап прямо с телефона — агент сразу продолжает работу.
- **Встроенные нейросети локально и без подписок** — готовый стек **Python `AI_env`** (`DeepFilterNet3`, `Demucs v4`, `VoiceFixer`, `Inworld Voice Isolator`, `Whisper`, диаризация) работает прямо у вас на ПК или внутри Docker-контейнера без платных облачных API.
- **Десктоп-версия никуда не исчезла** — если не нужен домашний сервер, просто установите нативный клиент для Windows, macOS или Linux и работайте полностью локально.

## ✨ Что умеет ADM

### 1. Поиск и загрузка исходников
- Синхронизация каталога с **Shikimori** и **Anime365** (метаданные, постеры, список серий, персонажи).
- Встроенный поиск торрентов (Nyaa / TokyoTosho) и загрузка по Magnet-ссылкам через **WebTorrent**.
- Скачивание серий с **Anime365** и роликов с **YouTube** через `yt-dlp`.

### 2. Субтитры, роли и работа с даберами
- Полноценный редактор субтитров (`.ass` / `.srt`) с чисткой тегов, извлечением надписей и контролем скорости чтения (CPS).
- **OCR-риппер хардсаба** — извлечение вшитых в видео субтитров с выделением зоны кадра.
- Умное разбиение скрипта по персонажам, назначение даберов с учётом глобального маппинга и **автоматическая рассылка ролей в Telegram**.

### 3. Приёмка дорожек, нейроочистка и QA
- **Telegram-сканер**: сбор аудиодорожек и фиксов от даберов напрямую из рабочих чатов и топиков.
- **Whisper QA и анализ звука**: автоматическая проверка уровня громкости, клиппинга, тишины и сверка озвученных фраз с текстом субтитров.
- **Нейросетевая обработка**: шумоподавление и изоляция голоса (**DeepFilterNet3**, **Demucs v4**, **VoiceFixer**, **Inworld Voice Isolator**) и автотайминг реплик.

### 4. Сведение, релиз и команда
- Мультитрековый QA-плеер поверх видео и **подготовка/экспорт пакета дорожек для звукорежиссёра** (DAW).
- Финальный рендер серии через **FFmpeg**, встроенный видеоредактор и генератор промо-обложек.
- Аналитика по проектам, срокам и продуктивности участников, плюс резервные копии на Яндекс.Диск.

## 📦 Как установить

Выберите удобный способ в зависимости от того, как вы планируете пользоваться студией.

### Вариант 1. Десктопное приложение (Windows, macOS, Linux)

Подходит, если вы работаете на одном компьютере:

1. Перейдите в раздел [**GitHub Releases**](https://github.com/SvatOwl/anime-dub-manager/releases).
2. Скачайте пакет под вашу систему:
   - **Windows**: `Anime Dub Manager Setup ... .exe` (установщик) или `Portable .exe`
   - **macOS**: `.dmg` (Apple Silicon / Intel) или `.zip`
   - **Linux**: `.AppImage` или `.deb`
3. Запустите приложение и при первом открытии в **Настройках** загрузите нейросетевую среду `AI_env` в один клик (или используйте встроенные инструменты без неё).

---

### Вариант 2. Домашний сервер на Umbrel OS (рекомендуется для 24/7)

Образ уже содержит **Node.js**, **FFmpeg**, **yt-dlp** и предсобранный **Python `AI_env`** для `linux/amd64` (Mini-PC / Umbrel Home) и `linux/arm64` (Raspberry Pi 5).

**Установка через Umbrel Custom App Store:**
1. Откройте интерфейс **Umbrel OS** → **App Store**.
2. Нажмите на меню (три точки справа вверху) → **Community App Stores**.
3. Добавьте URL этого репозитория:
   ```text
   https://github.com/SvatOwl/anime-dub-manager
   ```
4. Найдите **Anime Dub Manager** в магазине и нажмите **Install**.
5. Откройте приложение (по умолчанию порт `3000`) и при первом запуске выберите режим доступа: **с паролем** (рекомендуется при доступе с телефона или через Tailscale) или **открытый доступ в локальной сети**.

---

### Вариант 3. Docker Compose (любой Linux-сервер / NAS / VPS)

```bash
# 1. Клонируйте репозиторий (или скопируйте docker-compose.yml и .env.example)
git clone https://github.com/SvatOwl/anime-dub-manager.git
cd anime-dub-manager

# 2. Создайте файл .env на основе примера (при желании задайте токены доступа и Telegram-бота)
cp .env.example .env

# 3. Запустите готовый multi-arch образ из GHCR
docker compose up -d
```

После запуска откройте в браузере на ПК или телефоне `http://<IP-вашего-сервера>:3000`. Все проекты, видео, дорожки, кеш моделей и история решений куратора сохраняются в постоянном томе `./server_data` (`/data` внутри контейнера).

> Если нужно собрать образ локально из исходников с полным `AI_env`, выполните `docker compose up -d --build`.

---

### Вариант 4. Запуск из исходников (для разработчиков)

Требования: **Node.js 22+**, **npm**, **Python 3.10** (для сборки `AI_env`), **Git**.

```bash
# 1. Клонируйте репозиторий и установите зависимости
git clone https://github.com/SvatOwl/anime-dub-manager.git
cd anime-dub-manager
npm install

# 2. Запуск в десктопном режиме (React + Electron)
npm run electron:dev

# ИЛИ запуск в серверном режиме без Electron (веб-клиент + MCP + REST + Inbox)
ADM_SERVER_MODE=true npm run server:prod
```

Локальная сборка установщика Electron под текущую ОС:
```bash
npm run build:electron
```

## 🤖 Подключение локального AI-агента

В серверном режиме (`ADM_SERVER_MODE=true`) ADM предоставляет три равноправных интерфейса управления поверх одних и тех же контроллеров. Токен агента (`AGENT_TOKEN`) можно скопировать в веб-интерфейсе в **Настройки → Umbrel Сервер, AI-агент и Уведомления** или задать заранее через переменную `ADM_AGENT_TOKEN`.

- **MCP Streamable HTTP** (для Open WebUI, OpenClaw, n8n, контейнеров на Umbrel):
  - URL: `http://<server-host>:3000/mcp`
  - Заголовок: `Authorization: Bearer <AGENT_TOKEN>` (или `x-agent-token: <AGENT_TOKEN>`)
- **MCP Legacy SSE**:
  - Поток: `http://<server-host>:3000/sse` | Сообщения: `http://<server-host>:3000/messages`
- **MCP stdio** (локальный процесс):
  ```bash
  npm run mcp:stdio
  ```
- **REST API + OpenAPI v3.1**:
  - Схема OpenAPI: `GET http://<server-host>:3000/api/v1/openapi.json`
  - Список инструментов: `GET http://<server-host>:3000/api/v1/tools`
  - Инструкция для агента: `GET http://<server-host>:3000/api/v1/playbook`
- **CLI с JSON-выводом**:
  ```bash
  ADM_SERVER_URL=http://<server-host>:3000 ADM_AGENT_TOKEN=<AGENT_TOKEN> npm run cli -- overview
  npm run cli -- inbox --status pending
  ```

Подробный пошаговый регламент работы агента (от загрузки равки и распределения ролей до согласования с куратором) описан в [`docs/AI_AGENT_PLAYBOOK.md`](./docs/AI_AGENT_PLAYBOOK.md).
