# Развертывание Anime Dub Manager на Umbrel OS и домашнем сервере

Это руководство описывает запуск серверной версии **Anime Dub Manager** с полным переносом тяжелых вычислений (FFmpeg, yt-dlp, WebTorrent, `AI_env` с DeepFilterNet3, Demucs v4, VoiceFixer, Inworld Voice Isolator) на сервер и легким браузерным клиентом для ПК и смартфона.

> Существующая десктопная сборка Electron для Windows / macOS / Linux работает без изменений.

---

## Вариант 1: Установка на Umbrel OS (Custom App Store)

1. Откройте веб-интерфейс Umbrel OS -> **App Store** -> нажмите **⋮** (в правом верхнем углу) -> **Community App Stores**.
2. Добавьте URL репозитория вашего магазина приложений (содержащего папку `umbrel-app-store/`):
   ```
   https://github.com/SvatOwl/anime-dub-manager
   ```
3. Найдите **Anime Dub Manager** и нажмите **Install**.
4. Все проекты, серии, модели ИИ и файлы будут храниться в постоянном томе `${APP_DATA_DIR}/data` (внутри контейнера `/data`).

---

## Вариант 2: Запуск через Docker Compose (x86_64 и ARM64)

```bash
# 1. Скопируйте переменные окружения
cp .env.example .env

# 2. Запустите сервер (соберёт образ или скачает готовый из GHCR)
docker compose up -d
```

Откройте `http://<IP-адрес-сервера>:3000` на компьютере или телефоне:
- При первом запуске появится экран первоначальной настройки: выберите **«Защитить паролем»** (рекомендуется для доступа через интернет/Tailscale) или **«Открытый доступ в локальной сети»**.
- Перезапустить сервер вручную из исходников (кроссплатформенно):
  ```bash
  npm run server:prod
  ```

## Подключение AI-агента и уведомлений куратора

1. Перейдите в **Настройки -> Umbrel Сервер, AI-агент и Уведомления**.
2. Скопируйте:
   - **AGENT_TOKEN**
   - **MCP Streamable HTTP**: `http://<server>:3000/mcp`
   - **MCP Legacy SSE**: `http://<server>:3000/sse`
   - **REST OpenAPI 3.1**: `http://<server>:3000/api/v1/openapi.json`
3. Для уведомлений в Telegram укажите **Telegram Bot Token** и **Telegram Chat ID куратора**, затем нажмите **Сохранить настройки**.
4. Когда агент отправляет запрос на согласование, уведомление появляется во вкладке **Входящие** (на ПК и в нижней панели на телефоне) и приходит в Telegram с кнопками **«✅ Одобрить»** и **«❌ Отклонить»**. Также доступны команды бота: `/inbox`, `/approve <id>`, `/reject <id> <причина>`, `/note <id> <текст>`.

## Передача файлов с ПК/телефона на сервер

В браузерной версии вместо системных диалогов ОС автоматически открывается **Файловый менеджер сервера** (`/data`):
- Загружайте видео, аудиодорожки и субтитры (`.srt`/`.vtt` автоматически конвертируются в `.ass` при загрузке) прямо с компьютера или телефона.
- Скачивайте готовые серии и пакеты для звукорежиссера в один клик через кнопку **«Файлы сервера»** в боковом меню, мобильном меню или Настройках.
